Недельки без кода в свободное время 😴

В прошлом посте я писал, что вернулся из отпуска. После отпуска я планировал возобновить программирование в свободное время, но план не сложился. Такую ситуацию я замечал в моей жизни и раньше: если одну неделю ничего не делать по проектам в свободное время, то после этой недели вернуться к проектам бывает очень сложно.

Цифровое рисование 🖼️

Первую неделю после возвращения из отпуска я потратил на цифровое рисование. Сделал и выложил один рисунок. Спустя неделю собрал 179 плюсов в социальной сети ⭐ Для меня это хороший результат. Моему предыдущему рисунку потребовалось больше времени, чтобы собрать такое же количество плюсов. Предыдущий рисунок я делал уже очень давно: с тех пор прошёл почти год.

AI-поиск для персонального веб-сайта 🔍

Задумал сделать фичу: поиск по моим постам с помощью AI. Например, ввожу такие запросы:

  • Сколько плюсов собрал мой цифровой рисунок?
  • В каком году я купил новую видеокарту для AI?
  • В какой месяц я перенёс мой проект с SQLite на PostgreSQL?

Модель должна оценить по шкале от 0 до 10, насколько пост соответствует запросу, и вывести посты отсортированными по этой оценке. Для меня будет полезна эта фича, ибо я сам иногда задумываюсь над этими вопросами. Искать ответ уже можно, но неудобно: к примеру, могу ввести слово “рисунок” в мой имеющийся обычный поиск, но в результатах будут все посты, где рисунок упоминался, даже если ответа на конкретный вопрос в посте нет. К тому же, у слова “рисунок” есть формы и падежи.

Фича довольно таки простая: нужно лишь обернуть имеющиеся API в удобную веб-страницу. Единственная проблема - производительность, ибо мощная модель будет подолгу обрабатывать каждый пост. Надеюсь сделать эту фичу в ближайшее время, тогда поиск по моим дневникам станет намного удобнее 💹 Планирую опробовать маленькую модель: 4B, я её называю робо-крыса 🐁
