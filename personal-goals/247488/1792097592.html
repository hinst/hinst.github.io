AI Search for my Personal Website 🔍

I’m thinking about creating a feature that allows searching through my posts using AI. For example, I could enter queries like:

  • How many likes did my digital drawing get?
  • In what year did I buy a new GPU for AI?
  • In which month did I migrate my project from SQLite to PostgreSQL?

The model would evaluate how well each post matches the query on a scale of 0 to 10 and then output the posts sorted by that score. This feature would be very useful for me because I often find myself wondering about these things. While it is currently possible to find answers, it’s inconvenient: for instance, if I enter the word “drawing” into my existing standard search, all posts mentioning “drawing” will appear, even if they don’t contain the answer to a specific question. Additionally, language nuances like different forms and cases for the word “drawing” can make standard searches messy.

The feature is actually quite simple: it just involves wrapping the existing APIs into a user-friendly web page. The only issue is performance, as a powerful model will take a long time to process every post. I hope to get this feature ready soon; once it’s done, searching through my diaries will be much more convenient 💹 I plan to try out a small 4B model, which I call “robo-rat” 🐭
